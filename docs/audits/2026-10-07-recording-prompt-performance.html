8B GPU: correct on this validation moment


“The 'Workspace name' input field is empty, and the page now displays the message 'A name is required' with the subtext 'Enter a name to continue.'”


Both 8B cold runs reported the visible error correctly. A warm distinct moment correctly reported the rename state. This limited check supports keeping accuracy alongside timing; it does not prove 8B is best across workloads or that smaller models cannot be improved.


Quality requirements for every speed experiment


  • Preserve legible critical text, transient errors and chronological context.
  • Report visible results; avoid unsupported clicks, saves, intent or external effects.
  • Compare against labelled screenshots and manual review, not only JSON validity or model confidence.
  • Test that the receiving agent can access each image and complete the intended task.
